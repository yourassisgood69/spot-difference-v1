Spot the Difference — an original spot-the-difference game in plain browser JavaScript. Two near-identical hand-drawn scenes side by side (a sunny garden café, a harbour at dawn, a night market), click the differences to mark them, build combos, spend hints, and beat the clock across three rounds of rising difficulty. No libraries, no network, no build step; every scene is drawn by the game's own canvas code and every sound is generated in code.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. For screenshots, the game accepts a `?shot=` parameter (`start`, `play`, `round2`, `end`) that plays the real rules forward to a real game state.
